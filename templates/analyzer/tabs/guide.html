What raises CC?

  • +1if / elif branch
  • +1for / while loop
  • +1except clause
  • +1and / or in a condition
  • +1ternary x if c else y
  • +1assert, comprehension
  • 1base score per function

Blank and comment-only lines are excluded.

Commits vs churn

n_commits — how many commits touched the file.

churn — total lines added + deleted. Measures volume of editing, not frequency.

One huge rewrite gives few commits but high churn; many small tweaks give the opposite.

Rate of change change_rate

n_commits ÷ lifespan_days × 30 — commits per month between the first and last commit touching the file. Files changed only once score 0.

Logical coupling

coupling_strength = co-commits ÷ commits touching either file. coupling_degree = number of distinct co-change partners.
